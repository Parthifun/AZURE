Terraform

It is an open-source tool used to manage the Infrastructure as Code(Iac). With Terraform (or IaC tools), you write what you want in a file, and the tool automatically creates those resources for you in the cloud.

It is strated in 2014,
It is a software tool Created by HashiCorp,
It’s a Cross-platform tool.

Drawbacks of Manual Provisioning  Infrastructure
-Lack of Version Control,
-Documentation Heavy,
-Slow Provisioning. 

Key Features of Terraform
-Multi-cloud support        (we can lanuch servers in any cloud platform (AWS, Azure, GCP)by writing HCL program).
- State Management    (we can go back from any state to any state(like version))
- Large Ecosystem        (By default terraform provides the modules and resources by using them we can create infrastructures)
- Community Support    (IF there is any issues, any bugs, or any features that we want find it helps us)
- Integration with other tools  (We can integrate with tool(like CI/CD, Jenkins)) 
- HCL Language             (It is a Human Readable and express making easier for both developers & operators to work with Terraform)
Note: When you Integrate Terraform with CI/CD tool it is called Continuous Infrastructure.
